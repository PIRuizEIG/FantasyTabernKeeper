# Fantasy Tavern Keeper

Aplicación web interactiva de gestión estratégica y simulación por turnos basada en una ambientación RPG medieval, desarrollada como Proyecto Intermodular para el ciclo de **2.º de Desarrollo de Aplicaciones Web (DAW)**.

## 📌 Descripción del Proyecto
El jugador asume el rol de gestor de un asentamiento en crecimiento centrado en una taberna, gestionando recursos finitos (oro, población y materiales), publicando misiones para aventureros y procesando el avance de los días mediante turnos discretos.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript.
* **Backend:** PHP.
* **Base de Datos:** MySQL.
